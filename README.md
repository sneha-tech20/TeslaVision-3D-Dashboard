# TeslaVision 3D Dashboard

## 🚗 Project Overview
An interactive Tesla analytics dashboard built in Power BI for data visualization and business insights.

## Features
- Interactive Dashboard
- KPI Cards
- Accident Analysis
- Price by Model
- EMI Analysis
- Odometer Insights
- State-wise Distribution
- Model Filter
- 3D Tesla Visualization

## Tools Used
- Power BI
- DAX
- CSV Dataset
- HTML Content Visual
